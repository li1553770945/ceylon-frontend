# 10. 验收标准与重构路线

## 10.1 P0 验收标准

### 认证

- 用户可以注册、登录、退出。
- 刷新页面后 session 可恢复。
- 未登录访问工作台会跳转登录。
- 401/403 有明确提示。

### 项目

- 可以创建、查看、搜索、编辑、删除项目。
- 可以上传项目图标。
- 项目概览展示统计和版本视图。

### 版本视图与需求

- 可以创建/删除版本视图。
- 需求表格可加载。
- 可以新增、编辑、删除需求。
- 可以编辑优先级、状态、负责人。
- 基础搜索、筛选、排序可用。

### 团队

- 可以查看成员。
- 有权限用户可以邀请成员、修改角色、移除成员。

## 10.2 P1 验收标准

- 自定义列完整可用：新增、重命名、删除、编辑值。
- select 选项支持颜色和重命名。
- CSV/Excel 导入可预览、提交、刷新表格。
- 表格导出 Excel 可用。
- 个人资料头像和显示名可更新。
- CLI Token 创建、展示一次、撤销可用。
- CLI OAuth 授权确认页面可用。
- 中英日切换可用。
- 深色模式可用。

## 10.3 P2 验收标准

- 博客公开页和管理后台可用。
- Markdown 渲染支持 Mermaid、LaTeX、代码高亮。
- 管理员邀请码可用。
- AI Review Diff 可查看并 apply。
- 订阅页面有真实套餐状态。
- Analytics 可记录关键事件。
- PWA 安装体验可用。

## 10.4 重构路线

### 阶段 1：工程骨架

- 初始化 Next.js + TypeScript。
- 接入 MUI、next-intl、Zustand。
- 建立 API Client。
- 建立 AuthProvider、ThemeProvider、基础布局。

### 阶段 2：认证闭环

- 对接 `ceylon-backend` 登录/注册/session/logout。
- 完成路由守卫。
- 完成登录、注册、找回/重置密码。

### 阶段 3：工作台主链路

- Dashboard 项目列表。
- 项目概览。
- 项目设置。
- 成员管理。
- 版本视图列表。

### 阶段 4：需求表格

- 先实现只读表格。
- 再实现新增/编辑/删除。
- 再实现自定义列。
- 最后实现筛选、排序、列宽、批量、导入导出。

### 阶段 5：扩展能力

- 个人资料、设置、CLI Token。
- CLI OAuth 授权。
- 博客公开页与管理后台。
- 管理员邀请码。
- AI Review Diff。

### 阶段 6：打磨与测试

- 补 E2E 主流程。
- 补 API 契约测试。
- 移动端与深色模式检查。
- 生产构建和 standalone 部署。

## 10.5 建议 E2E 用例

| 用例 | 优先级 |
| --- | --- |
| 注册 -> 登录 -> Dashboard | P0 |
| 创建项目 -> 创建视图 -> 新增需求 | P0 |
| 编辑需求状态/优先级/负责人 | P0 |
| 邀请成员 -> 修改角色 -> 移除 | P0 |
| 创建自定义列 -> 编辑值 -> 删除列 | P1 |
| CSV 导入 -> 预览 -> 导入成功 | P1 |
| 创建 CLI Token -> 撤销 | P1 |
| 管理员创建博客 -> 公开页查看 | P2 |
| AI Review Apply All | P2 |
