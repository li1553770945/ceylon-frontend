# 4. 页面与功能模块

## 4.1 公开首页

### 功能

- 展示 CEYLON 品牌、定位和核心价值。
- 根据登录态显示“进入控制台”或“免费开始使用”。
- 展示核心能力、CLI/AI 集成、定价摘要、博客入口。
- 支持中英日文案。

### 验收

- 首屏可清晰识别产品名称与价值主张。
- CTA 在未登录时进入注册/登录，在已登录时进入 Dashboard。
- 移动端布局不遮挡、不溢出。

## 4.2 登录、注册、找回密码

### 登录

- 输入邮箱、密码。
- 调用后端登录 API。
- 登录成功后恢复 session 并跳转 Dashboard。
- 支持错误提示、loading、超时处理。

### 注册

- 输入邮箱、密码、显示名称。
- 支持头像选择和预览。
- 可接入邀请码策略。
- 注册完成后根据后端策略进入邮箱验证、登录页或直接进入 Dashboard。

### 找回与重置密码

- 找回密码提交邮箱。
- 重置密码页面解析 code/token。
- 调用后端验证 token 和更新密码 API。

## 4.3 Dashboard 项目列表

### 功能

- 获取当前用户可访问项目。
- 展示项目名称、描述、图标、所有者/成员关系。
- 支持搜索项目。
- 创建项目：名称、描述、图标上传。
- 删除项目。

### 前端状态

- `loading`：项目列表骨架屏。
- `creating`：创建按钮 loading。
- `searchQuery`：来自 URL query，便于分享/刷新保留。

## 4.4 项目概览

### 功能

- 展示项目标题、图标和描述。
- 展示统计卡片：总需求、已完成、进行中、Bug。
- 展示版本视图列表。
- 跳转团队、设置、具体视图。

### 数据接口

- `GET /api/v1/projects/:projectId/full`
- `GET /api/v1/projects/:projectId/stats`

## 4.5 项目设置

### 功能

- 编辑项目名称、描述、图标。
- 创建版本视图。
- 删除版本视图。
- 删除项目。
- 非所有者/无权限用户应隐藏或禁用危险操作。

### 验收

- 保存成功后页面即时反映最新信息。
- 删除项目后跳转 Dashboard。
- 删除版本视图需要二次确认。

## 4.6 团队成员

### 功能

- 展示项目成员、邮箱、头像、角色。
- 搜索用户并邀请加入项目。
- 修改成员角色：`read`、`write`、`admin`。
- 移除成员。

### 权限体验

- Owner 和项目 admin 可管理成员。
- 普通成员只读展示成员列表。
- 权限不足时后端返回 403，前端展示友好错误。

## 4.7 版本视图需求表格

这是工作台核心页面。

### 固定字段

| 字段 | 说明 |
| --- | --- |
| 编号 | 固定宽度，不参与拖拽列宽 |
| 标题 | 需求标题，必填 |
| 优先级 | 当前实现有 P0-P5 表格体验，同时历史类型中存在数值优先级 |
| 状态 | `pending`、`in_progress`、`completed`、`rejected` |
| 负责人 | 项目成员 |

### 自定义列

| 类型 | 说明 |
| --- | --- |
| `text` | 文本 |
| `select` | 单选标签，支持选项颜色和重命名 |
| `person` | 人员字段 |

### 表格交互

- 表格骨架屏。
- 搜索。
- 筛选：等于、不等于、包含、未完成。
- 排序。
- 隐藏/显示列。
- 拖拽调整列宽。
- 新增列、重命名列、删除列。
- 新增需求。
- 内联编辑需求字段。
- 批量选择、批量删除。
- 导出 Excel。
- 行拖拽排序的前端体验可保留，但排序持久化需与后端确认。

### 同步策略

当前实现存在本地 pending create/patch/delete 队列和延迟 flush。新项目可保留该体验，但必须：

- 后端接口支持幂等或返回明确冲突。
- 前端显示同步失败提示。
- 页面刷新前尽量 flush pending 操作。

## 4.8 数据导入

### 功能

- 插入菜单中提供“插入行”和“从 CSV/Excel 导入”。
- 支持 CSV、TSV、TXT、XLSX、XLS。
- 前端解析文件并展示预览。
- 用户确认后提交后端导入 API。
- 导入成功后刷新表格。

### 映射规则

- 标题列：`标题`、`title`、`Title`。
- 描述列：`描述`、`description`、`Description`。
- 优先级：支持 P0-P5 或高/中/低映射。
- 状态：支持中文/英文状态别名。
- 自定义列：同名匹配版本视图列。

## 4.9 评审 Diff

### 功能

- 展示 AI/导入生成的 review session。
- 按 item 展示新增、修改、删除差异。
- 支持单项决策和 Apply All。
- 评审完成后返回版本视图。

### 当前组件

- `components/review/ReviewDiffViewer.tsx`
- `components/review/ReviewCard.tsx`
- `components/review/SubmitDialog.tsx`

## 4.10 个人资料与账号设置

### 个人资料

- 展示邮箱、显示名、头像。
- 支持头像上传和资料更新。
- 更新后刷新全局 auth store。

### 设置

- 退出登录。
- 删除账号入口。
- CLI Token 列表。
- 创建 CLI Token。
- 撤销 CLI Token。

## 4.11 CLI OAuth 授权

### 功能

- 根据 URL 中 device/session 参数获取授权请求。
- 未登录时引导登录。
- 已登录时展示授权应用、权限和确认按钮。
- Approve/Deny 后给 CLI 轮询端返回状态。

## 4.12 管理后台

### 管理首页

- 展示基础 analytics：用户数、项目数、需求数、博客数等。

### 邀请码

- 创建邀请码。
- 设置最大使用次数、过期时间、备注。
- 禁用/删除邀请码。

### 博客管理

- 博客列表，支持草稿/发布/归档状态。
- 新建/编辑博客。
- Markdown 编辑器支持编辑/预览/分屏。
- 字段包括 slug、标题、副标题、分类、状态、封面、摘要、正文、SEO 标题、SEO 描述。

## 4.13 订阅页

当前已有订阅等级类型：`free`、`pro`、`team`、`enterprise`。前端应提供：

- 当前套餐展示。
- 套餐权益对比。
- 升级入口。
- 企业版联系入口。

支付闭环可作为 P2，具体由后端和支付平台决定。
